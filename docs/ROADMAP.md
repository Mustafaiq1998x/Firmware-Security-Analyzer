# Roadmap

## v0.2
- Optional integration with established firmware unpacking tools in an isolated
  environment, with explicit opt-in and extraction limits.
- Better ELF metadata and architecture detection.
- Configurable rule packs with rule identifiers and severity rationale.

## v0.3
- Normalizer for selected NVD JSON feed formats with tests.
- SBOM extraction/import and component inventory.
- Vendor advisory references and confidence tracking.

## v1.0
- Reproducible analysis profiles, signed reports, CI workflow, plugin interface,
  and documented false-positive evaluation.
